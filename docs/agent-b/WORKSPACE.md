## Known issues / rough edges

_(Running list of anything you're leaving unfinished, hacky, or worth a second look — not a bug tracker, just enough that the other agent (or you, next session) isn't surprised. Clear an item when it's fixed; move anything genuinely blocking into `docs/common/04-BLOCKERS.md` instead.)_

- **`.env` is never loaded into `process.env` by this codebase** — no `dotenv` dependency, no `--env-file` flag anywhere. Any `gate` command touching `DodoCreditLedger` (`fund`, `run` against a commit command) needs the shell loaded first: `set -a && source .env && set +a` (Git Bash/POSIX). Skipping this produces a misleading `DODO_PAYMENTS_API_KEY environment variable is missing` error (the SDK's own default var name, not `DODO_API_KEY`). Documented in `.env.example`'s header comment. Worth remembering on whatever machine runs the live 1 Aug demo — a fresh terminal there needs the same step, or the same confusing error will show up live.
- Blinkit sessions go stale between rehearsal sessions (found this session — `whoami` returned `AUTH_REQUIRED` even though it had worked in a prior session) — always re-check `webcmd blinkit whoami` at the start of a session before assuming the cart/login state carried over, per Plan Phase 1's own checklist item 1.
- **Receipt `rcp_ms66xl2ef9771fa00056` (the real Beat 5 receipt) has `network_order_id: undefined`** — the extraction fix (ADR-011) landed after this receipt was already signed, and an already-signed receipt is never retroactively edited (would break its own signature). Every receipt from a commit-path run going forward will carry the real value. Not a blocker, just don't be surprised this one specific receipt is missing that one field.
- **`npm run build` leaves `dist/`, and `npm test` then globs it too** — the suite silently reports 90 tests instead of 45, running everything twice (the test script has no path argument, per Phase 0's own workaround for a Node quirk). Harmless but misleading; `rm -rf dist` restores honest counts. Worth knowing before reading a surprising test number. The demo *should* be run from a build (`node dist/cli/gate.js` — it's ~1 min faster across a full run than `ts-node`), so this will keep recurring.

Cosmetic, not a security issue — confirmed again this session, not a new finding.

- `ManifestCommand` in `manifest.ts` only types the 3 fields (`site`, `name`, `access`) actually consumed — the real payload has 14 fields per command. If a future phase needs another field (e.g. `columns` for display), extend the interface then rather than speculatively now.
